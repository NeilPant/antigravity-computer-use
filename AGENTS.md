# Project instructions

Before changing this repository, read and follow [CONTRIBUTING.md](CONTRIBUTING.md). Work within the agreed task and report reproducible evidence for behavior and performance changes.

For Computer Use refinements, Codex agents must start by observing a live Antigravity App run through Codex's built-in Computer Use. Follow the [live comparison workflow](CONTRIBUTING.md#live-comparison-for-codex-agents) before choosing a plugin change.
